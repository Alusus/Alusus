# دليل مدير الحزم (Apm)

مدير حزم الأسس (محا أو apm) ينزل الحزم مباشرة من موقع GitHub ويمكن استخدامه عبر سطر الأوامر أو من داخل البرنامج مباشرة. للحصول على تعليمات استخدام مدير الحزم من سطر الأوامر اكتب الأمر التالي:

```
$ محا مساعدة
```

```
$ apm help
```
أما استخدام مدير الحزم من داخل البرنامج فيتم باستخدام دالة `اشمل_حزمة` (importPackage).

```
اشمل "مـحا.أسس"؛
مـحا.اشمل_حزمة("&lt;الناشر&gt;/&lt;اسم الحزمة&gt;@&lt;الإصدار&gt;" [، "&lt;اسم الملف&gt;"])؛
مـحا.اشمل_حزمة("&lt;الناشر&gt;/&lt;اسم الحزمة&gt;@&lt;الإصدار&gt;"، { "&lt;اسم الملف 1&gt;"، "&lt;اسم الملف 2&gt;"، ... })؛
```

```
import "Apm.alusus";
Apm.importPackage("&lt;author&gt;/&lt;pkg name&gt;@&lt;version&gt;" [, "&lt;filename&gt;"]);
Apm.importPackage("&lt;author&gt;/&lt;pkg name&gt;@&lt;version&gt;", { "&lt;filename1&gt;", "&lt;filename2&gt;", ... });
```

يجب تحديد رقم الإصدار ويمكن أن يأخذ إحدى الصيغ التالية:
* **&lt;رئيسي&gt;**: يطابق أحدث إصدار يحمل رقم الإصدار الرئيسي المحدد.
* **&lt;رئيسي&gt;.&lt;ثانوي&gt;**: يطابق أحدث إصدار يحمل رقمَي الإصدار الرئيسي والثانوي المحددَين.
* **&lt;رئيسي&gt;.&lt;ثانوي&gt;.&lt;ترقيعي&gt;**: مطابقة تامة للإصدار.
الصيغة الثانية من الدالة تمكن المستخدم من شمول عدة ملفات من الحزمة دفعة واحدة. استخدام الصيغة الثانية لشمول عدة ملفات أسرع من استدعاء الصيغة الأولى عدة مرات، لأن كل استدعاء لهذه الدالة يؤدي إلى قراءة بيانات من موقع GitHub..
أثناء تطوير الحزم غالبا ما يحتاج المطور لتجربة الحزمة محليًا قبل دفع التعديلات إلى المستودع. يمكن للمستخدم استخدام أمر الربط لربط حزمة معينة مع مجلد محلي فيقوم عندها مدير الحزم باستخدام النسخة المحلية بدل تنزيل نسخة المستودع.
أمر الربط يجب أن يُنفذ داخل مجلد المشروع الذي يستخدم الحزمة ويكون بهذه الصيغة:

```
$ cd &lt;example_project_folder&gt;
$ apm link &lt;author&gt;/&lt;package_name&gt;@&lt;release&gt; &lt;path_to_local_package_copy&gt;
```
يمكن إزالة الرابط باستخدام الأمر `افصل` وبهذه الصيغة:

```
$ cd &lt;example_project_folder&gt;
$ apm unlink &lt;author&gt;/&lt;package_name&gt;@&lt;release&gt;
```

يمكن التحكم في سلوك جلب الحزم باستخدام خيارات البرنامج التالية التي تُمرَّر لمترجم الأسس وقت التشغيل:
* **محا_حدث** (**apm_check_updates**): يجبر مدير الحزم على جلب قائمة الإصدارات المتاحة من GitHub
لتحديد أحدث إصدار يطابق المواصفة المطلوبة، وتنزيله إذا لم يكن متاحًا محليًا. بدون هذا الخيار يستخدم مدير الحزم أول
نسخة محلية يجدها دون التحقق من وجود إصدارات أحدث.
* **محا_أنعش** (**apm_refetch**): يجبر مدير الحزم على تنزيل الحزمة دائمًا من GitHub متجاهلًا
أي نسخ محلية حتى لو كانت موجودة.
